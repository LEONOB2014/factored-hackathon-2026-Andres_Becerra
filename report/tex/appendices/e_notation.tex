\chapter{Notation index}\label{app:notation}

Symbols are defined where they are first used. The report keeps the notation of each method's literature, so a few
letters, such as $\lambda$, $\pi$, $q$ and $G$, mean different things in different chapters; within a chapter each
letter has one meaning. This index lists the symbols that recur across chapters and the named statistics, each with the
place it is defined.
