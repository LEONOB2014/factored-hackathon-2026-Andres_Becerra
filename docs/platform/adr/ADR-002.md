# ADR-002 · Airflow 3 with Astronomer Cosmos for orchestration

Status: accepted (2026-10)

## Context
Pipelines span ingestion, dbt, ML, streaming control and compliance jobs; regulators expect run evidence and approvals.

## Decision
Airflow 3.1 (Composer 3 in GCP), asset-based scheduling, Cosmos task groups per dbt layer, HITL approval operators, OpenLineage provider; platform code in an isolated venv.

## Consequences
Per-model visibility and lineage, managed cloud option, native approvals. Cosmos adds task overhead (each model is a process); acceptable at this scale, revisit with dbt Fusion or Cosmos watcher mode.

## Alternatives considered
Dagster (strong asset model, no managed offering in the target cloud); dbt Cloud jobs only (no ML/streaming control).
