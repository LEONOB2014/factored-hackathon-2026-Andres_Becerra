# ADR-001 · Lakehouse with medallion zones and a Kimball core

Status: accepted (2026-10)

## Context
Data arrives as daily files with defects that must stay auditable; consumers need both governed dimensional data and denormalized marts.

## Decision
Landing → bronze (typed, append-only, digests) → silver (stg/int) → gold (SCD2 dims + facts + marts), plus features, graph, knowledge, privacy, serving and audit zones. dbt implements silver and beyond.

## Consequences
Clear trust levels and data classes per zone; repairs visible as flags, never overwrites. More layers to maintain; mitigated by generated lineage and contracts.

## Alternatives considered
Single wide-table warehouse (rejected: grain mixing and leakage); data vault (rejected for now: heavier modelling than the source volume justifies).
