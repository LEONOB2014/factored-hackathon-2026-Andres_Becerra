# ADR-010 · Federated graph learning across countries

Status: accepted (2026-10)

## Context
Cross-country patterns matter (mules, merchants) but rows cannot leave their residency region.

## Decision
Per-country GraphSAGE clients with FedAvg / DP-FedAvg, compared every run with local-only and centralised baselines; Flower with secure aggregation in production.

## Consequences
Learning across silos without moving rows; measured cost of federation. On this synthetic data all variants are at chance (no signal), which is itself reported.

## Alternatives considered
Centralised training in one region (rejected: residency).
