# ADR-009 · Scope of differential privacy

Status: accepted (2026-10)

## Context
Aggregates shared across borders or externally can leak individuals; operational decisions need exact data.

## Decision
DP (OpenDP locally, BigQuery DP clause in cloud) for aggregate releases, synthetic data and federated updates, with a budget debited in the immutable ledger before release; never for fraud/AML/credit decisions or statutory reports.

## Consequences
Formal guarantees where data leaves the trust boundary, no utility loss where exactness is required.

## Alternatives considered
DP everywhere (rejected: breaks decisions and reports); no DP (rejected: cross-border analytics risk).
