# ADR-004 · Neo4j for GraphRAG and the entity graph

Status: accepted (2026-10)

## Context
Compliance questions traverse regulation → control → model; fraud/AML need neighbourhood queries; GNN results need a home.

## Decision
Neo4j holds the KB graph (Document/DocVersion/Chunk/Entity with vector index) and a token-only entity graph; both rebuilt from governed sources.

## Consequences
Expressive traversals, vector index co-located with the graph. Community edition lacks RBAC granularity and clustering; production uses Enterprise/Aura in-region.

## Alternatives considered
Graph in Postgres (rejected: traversal ergonomics); Spanner Graph (option on GCP, evaluated later).
